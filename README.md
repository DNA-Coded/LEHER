# Lahar

A modern web application featuring an interactive 3D ScrollGlobe landing page built with React, TypeScript, Tailwind CSS, and shadcn UI component architecture.

## Features

- **Interactive 3D ScrollGlobe**: Scroll-driven dynamic 3D globe animation using sub-pixel transforms and `requestAnimationFrame`.
- **Shadcn Project Structure**: Modular design system using `src/components/ui/` primitive component patterns.
- **Tailwind CSS v4 Integration**: Customized CSS variables, fluid responsive typography, and keyframe animations.
- **TypeScript Type Safety**: Strict TypeScript configuration supporting path aliases (`@/*`).

## Getting Started

### Development Server

Run the development server locally:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Production Build

Build the optimized production bundle:

```bash
npm run build
```
